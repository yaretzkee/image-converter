# Changelog

All notable changes to this project are documented here.

The project follows [Semantic Versioning](https://semver.org/).

## [1.0.1] - 2026-09-07

### Added

- SVG, AVIF, and WebP input support.
- ICO output support.
- High-resolution SVG rasterization, including direct rendering at the requested resize dimensions.
- Application version shown in the window title.

## [1.0.0]

### Added

- Initial Image Format Converter release.
- PNG, JPG/JPEG, TIFF/TIF, and BMP inputs.
- PNG, WebP, and AVIF outputs.
- Batch conversion, drag-and-drop, resizing, output-folder selection, and light/dark theme support.
